Use it

Add one stylesheet, put class="mm" on a wrapper, and compose screens from the classes below.

<link rel="stylesheet" href="https://cdn.jsdelivr.net/gh/gitcamy/megamind-labs-ui@main/megamind-labs-ui.css"> <body class="mm mm-canvas"> <div class="mm-screen mm-screen--phone"> <h1 class="mm-title">Welcome back</h1> <input class="mm-input" placeholder="Email address"> <div class="mm-spacer"></div> <button class="mm-btn mm-btn--block">Continue</button> </div> </body>

Foundations

Everything is a CSS variable, so a team can retheme the kit in ten lines.

Grey means undecided

Fills stand in for anything not designed yet: icons, photos, charts, maps. If it is grey, nobody has to defend it.

Ink means it matters

Near-black is reserved for the one primary action, the active state, and the number the screen exists to show.

One line weight

Every border is 1px in the same grey. Emphasis comes from fill and type weight, never from thicker lines.

No color, even for errors

Danger is a dashed outline, errors are a bold message with a mark. Color decisions belong to the visual design pass.
