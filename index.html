Get started

Megamind Labs UI is a minimalistic wireframe kit for starting projects and getting them working before you design them. Link one stylesheet and build screens with plain HTML, React, or any AI tool that writes front-end code.

Set it up

  1. Link the stylesheet. Add the link below to the head of your page. It is the only file you need.
  2. Set up the canvas. Put class="mm mm-canvas" on your body, then wrap each screen in class="mm-screen mm-screen--phone".
  3. Build your screens. Compose them from the components below, or give PROMPT.md to your AI tool so it builds with the same classes.
<link rel="stylesheet" href="https://cdn.jsdelivr.net/gh/gitcamy/megamind-labs-ui@main/megamind-labs-ui.css"> <body class="mm mm-canvas"> <div class="mm-screen mm-screen--phone"> <h1 class="mm-title">Welcome back</h1> <input class="mm-input" placeholder="Email address"> <div class="mm-spacer"></div> <button class="mm-btn mm-btn--block">Continue</button> </div> </body>

Foundations

Every color, space, radius, and type size in the kit is a named CSS variable, such as --mm-ink or --mm-r-md. Components never hard-code a value. They read the variable by name, so changing one variable updates every button, border, and label that uses it.
